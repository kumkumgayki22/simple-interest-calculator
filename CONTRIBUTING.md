# Contributing

Thank you for considering a contribution to Simple Interest Calculator.

## How to contribute

1. Fork this repository.
2. Create a new branch for your change.
3. Make your update and test it locally.
4. Commit your work with a clear message.
5. Open a pull request that explains the change.

## Guidelines

- Keep changes focused and easy to review.
- Follow the existing style and naming conventions.
- Be respectful and follow the project's Code of Conduct.
